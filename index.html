RideOn: Designing Semiautonomous Cycling for Blind and Low-Vision Riders

Anonymous Research Project

This project explores a semi-autonomous, human-powered cycling system designed to support blind and low-vision riders through autonomous steering, safety interventions, multimodal feedback, and environmental awareness.

Teaser figure or system overview figure will be placed here.

Overview

Cycling provides transportation, recreation, exercise, and independent mobility, but many cycling tasks depend heavily on visual perception. This project investigates how shared autonomy can support blind and low-vision riders while preserving meaningful rider participation and control.

Shared Autonomy

The rider provides propulsion while the system assists with steering and safety-critical interventions.

Multimodal Feedback

Audio and vibrotactile feedback communicate system actions and support awareness of the surrounding environment.

Real-World Evaluation

The system was iteratively evaluated with blind and low-vision riders in real-world cycling environments.

System

The platform integrates sensing, onboard computation, actuated steering and braking, rider input, and multimodal feedback into a semi-autonomous recumbent cycle.
